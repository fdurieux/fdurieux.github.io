# Legible

Site source for <https://fdurieux.github.io/>: the entry page of a programme
to make everything upstream of code query-able for humans and AI, and
quality-gated before it is handed to a developer or a dev-agent.

- `index.html` — the page, hand-written HTML with inline CSS, no build step.
- `ROADMAP.md` — the programme's record: projects, their artefact class,
  gate state and trigger, with dated log entries. The page is a view of it.

The programme's projects live in their own repositories and keep their own
roadmaps; this one only lists them. Shipping today:
[pumllint](https://github.com/fdurieux/pumllint) and
[aris2puml](https://github.com/fdurieux/aris2puml).

## Working on the page

Adopter register: assume no prior knowledge of the artefacts, the tools or
the SAFe® pipeline. Name a concept before using it. Every value claim carries
an evidence tag (measured, research, mechanism). A tool is marked "covered"
only when it exits non-zero on findings; a project is marked "planned" only
when it has a named artefact class and stays so until a repository exists.
